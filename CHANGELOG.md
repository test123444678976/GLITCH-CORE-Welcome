# Changelog

All notable changes to GLITCH//CORE Welcome are documented here.

## 0.2.0 — 2026-11-15

- Added a headless `--system-info` command.
- Added copy-to-clipboard and About actions to the GTK window.
- Improved GTK layout, labels, button states and version display.
- Improved OS-release parsing and memory-information fallback.
- Fixed the generated launcher newline in the Makefile installer.
- Added staged-installation checks and desktop-entry validation to CI.
- Expanded CI coverage to Ubuntu 24.04 and 26.04.
- Clarified the prototype status and package-manifest limitations.
